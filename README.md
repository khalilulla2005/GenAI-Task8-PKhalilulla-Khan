# Assignment 8: Streamlit (Basic App Building)

This assignment contains 4 simple, interactive Streamlit web apps.

## How to Run the Apps
To run any of these apps, open your terminal in this folder and use the `streamlit run` command:
`streamlit run app_basic.py` (replace with other filenames for other tasks).

## Code Execution Outputs (Simulated UI)

Since Streamlit renders in the browser, here is a description of the UI outputs generated by each app when tested:

### Task 1: Basic App (app_basic.py)
**UI Components:** Title, Text Input, Button.
**Output:**
- Displays title: "Welcome to Streamlit!"
- Text box prompts: "Enter your name:"
- If user enters "John" and clicks "Greet Me", the screen displays: **"Hello, John!"**

### Task 2: Price Calculator (app_discount.py)
**UI Components:** Number Input, Slider, Button, Success Box, Table.
**Output:**
- User enters Price: 1000
- User sets Discount slider to: 10%
- Upon clicking "Calculate", a green success box appears:
  `Original Price: $1000.00 | Discount: 10% | Final Price: $900.00`
- A table is displayed below it:
  | Before Discount | After Discount |
  | :--- | :--- |
  | $1000.00 | $900.00 |

### Task 3: Product Form (app_product_form.py)
**UI Components:** Sidebar (Text Input, Selectbox, Number Input, Button).
**Output:**
- The user fills the sidebar: Name = "Laptop", Category = "Electronics", Price = 1200.
- Clicking "Add Product" displays in the main window:
  `Product added successfully!`
  **Name:** Laptop
  **Category:** Electronics
  **Price:** $1200.00

### Task 4: Mini Dashboard (app_dashboard.py)
**UI Components:** Selectbox, Metric, Bar Chart.
**Output:**
- A dropdown menu allows selecting a month (e.g., "March").
- A large metric card displays: **Sales for March** : **$900**
- A bar chart renders showing the sales data for all months (Jan: 1200, Feb: 1500, Mar: 900, Apr: 2000).
